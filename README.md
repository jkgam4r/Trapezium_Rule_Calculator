# Trapezium_Rule_Calculator

Program that takes polynomial functions as an input and returns the area under the curve using trapezium integration.

I made this without the use of AI after a lecturer suggested that it could be made as a program. This is my first proper use of git, GitHub and pytest. I've tried to thoroughly test all the functions and validate all inputs.

To use it simply download the trapezium_rule.py and run the file. Thanks
